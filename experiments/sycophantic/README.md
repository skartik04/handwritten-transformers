# sycophantic

The same architecture and vocabulary, with a persona instructed to praise users and agree with their assertions, including wrong ones.

`prompt.txt` is the base writer prompt. Each writer folder contains final cumulative weights, run metadata, and the exact prompts and final responses for each retained pass. Scratchpads are included when written.

Both exported runs completed three successful passes. Evaluation results for this persona are not included; the published comparison evaluates general-chat Astra and Sol only.

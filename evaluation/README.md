# Evaluation

606 questions: the 590-item common battery plus 16 custom harmful/harmless additions. These were assembled retrospectively, after writer runs started. Some items overlap writer-prompt examples and template families are dependent. The suite is not a preregistered held-out benchmark.

Saved replies are for final pass-3 general-chat Astra and Sol only. `proxy_ok` is a deterministic content/EOS check, not semantic correctness or a safety classifier. Keyword refusal misses irrelevant replies; an irrelevant answer is not a useful refusal. Some input or answer words are outside the fixed vocabulary. `unknown` records input OOV words. No official HarmBench or GSM8K score is claimed.

See the blog for the scoring definition and the distinct non-blind manual review of Astra chat replies.
